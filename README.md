# 苏季酒店数据分析系统

纯本地、单文件夹绿色便携版酒店运营数据分析系统，基于去呼呼客栈管家导出报表，实现数据自动清洗、计算、聚合、可视化、整点自动采集功能。

## ✨ 核心特性
- 🟢 **零依赖绿色版**：双击即可运行，无需安装Python/Node/数据库，单文件夹随拷随用
- 📊 **全维度数据统计**：小时/日/月/季/年五级数据，出租率、单房收益、累计房费自动计算
- ⏰ **整点自动采集**：自动登录去呼呼后台导出报表，无需人工操作，失败自动重试
- 📈 **可视化图表**：趋势图、热力图、星期规律、定价象限图，辅助价格决策
- 🔒 **数据安全**：所有数据本地存储SQLite，不上传云端，自动备份防丢失
- 🚀 **24小时稳定运行**：系统托盘后台运行，异常不崩溃，自动重算数据联动

## 📦 快速开始
### 直接使用绿色版
1. 下载最新发布的压缩包，解压到任意文件夹
2. 双击`酒店数据分析系统.exe`启动
3. 系统自动打开浏览器访问 `http://127.0.0.1:8080`
4. 首次使用进入「系统设置」配置去呼呼账号密码，开启自动采集

### 源码运行（开发调试）
#### 环境要求
- Python 3.11
- Node.js 18+

#### 后端启动
```bash
# 安装依赖
pip install -r requirements.txt
# 安装Playwright浏览器
playwright install chromium
# 启动后端
python main.py
```

#### 前端启动
```bash
cd frontend
# 安装依赖
npm install
# 开发模式启动
npm run dev
# 打包前端
npm run build
```

## 🧮 计算口径（统一标准）
总房间数固定为113间，所有层级计算统一公式：
| 维度 | 公式 |
|------|------|
| 小时级 | 出租率 = 已售/113*100%<br>单房收益 = 累计房费/113 |
| 日级 | 出租率 = 售出/113*100%<br>单房收益 = 累计房费/113 |
| 月级 | 出租率 = 月总售出/(113*当月天数)*100%<br>单房收益 = 月总房费/(113*当月天数) |
| 季度级 | 出租率 = 季总售出/(113*当季天数)*100%<br>单房收益 = 季总房费/(113*当季天数) |
| 年度级 | 出租率 = 年总售出/(113*有效天数)*100%<br>单房收益 = 年总房费/(113*有效天数) |

## ⚙️ 自动采集配置
1. 进入「系统设置」页面
2. 开启自动采集开关
3. 填写去呼呼后台登录地址、账号、密码
4. 建议采集间隔60分钟，整点后延迟2分钟执行，避免接口拥堵
5. 点击「测试采集」验证是否正常
6. 首次登录如果有验证码，需要手动修改`auto_collector.py`中的元素选择器

### 元素选择器修改说明
去呼呼后台页面更新后，可能需要修改`app/core/auto_collector.py`中的CSS选择器：
1. 打开去呼呼后台，按F12打开开发者工具
2. 用元素选择器点击对应按钮/输入框
3. 复制正确的CSS选择器替换代码中对应位置

## 📦 打包绿色版
1. 先打包前端：`cd frontend && npm run build`
2. 复制Playwright安装的Chromium到根目录`chromium`文件夹
3. 执行打包命令：`pyinstaller build.spec`
4. 打包完成后将`data`目录模板、`chromium`目录复制到输出文件夹
5. 整个文件夹即可拷贝到其他电脑直接运行

## ⚠️ 注意事项
1. 数据目录`data`独立存放，升级时只替换exe和runtime目录，保留data即可不丢失历史数据
2. 建议每周重启一次程序，释放浏览器残留资源
3. 自动采集最低间隔不要小于30分钟，避免触发去呼呼风控
4. 数据库自动每6小时备份一次，保留30天备份，数据误删可从backup目录恢复
5. 所有计算结果保留2位小数，手动修改下层数据后会自动向上重算所有关联数据

## 🔧 常见问题
### Q: 自动采集失败怎么办？
A: 查看data/logs目录下的日志，常见原因：
- 账号密码错误
- 页面元素选择器失效，需要更新auto_collector.py
- 网络问题，程序会自动重试2次
- 登录需要验证码，建议首次手动登录后保存Cookie

### Q: 数据计算不对怎么办？
A: 进入系统设置点击「全量重算」，会从小时数据开始重新计算所有层级数据。

### Q: 怎么备份数据？
A: 直接复制整个data文件夹即可，或者从data/backup目录取最近的备份文件。
